🇪🇸 Descripción (Español)

Es una herramienta ligera y local diseñada para streamers que desean aumentar la interacción con su audiencia a través de voces personalizadas.

TTS-DC 🎙️ permite integrar un sistema de Text-to-Speech (TTS) directamente en OBS. Cuando un espectador utiliza una palabra clave en el chat, el programa reproduce el mensaje con la voz de un personaje famoso que hayas configurado previamente.

Lo mejor de TTS-DC es su eficiencia: se ejecuta de forma local para minimizar el impacto en el rendimiento de tu PC.

It is a lightweight, local tool designed for streamers who want to increase interaction with their audience through custom voices.

TTS-DC 🎙️ is a lightweight, local application designed for streamers to enhance audience engagement using custom voices. It integrates seamlessly with OBS as a Text-to-Speech engine.

When a viewer triggers a specific keyword in your chat, the program plays the message using the voice of a celebrity or character you've pre-configured. Since it runs locally, it ensures low latency and minimal CPU usage.
